# 发布检查

1. 检查完整 diff，运行类型检查、测试、构建、Linux CLI probe 及依赖审计。
2. 运行 `npm run release:check`，检查源码、示例、文档链接、依赖锁和可达历史；
   使用专用秘密扫描器检查工作树与历史，人工复核账户标识、私有 URL 和日志。
3. 核对文档中的功能与用法、CLI 版本及命令目录，更新特殊适配说明。
4. 保留 MIT、上游 CLI 及依赖许可，核对版本元数据和 CLI checksum。
5. 在独立环境验证授权、续期、文件和 Cron，记录结果。CI 使用合成数据；生产发布
   通过显式部署完成，实例升级参照 [版本升级](upgrade.md)。
6. 撰写版本说明，介绍用户可见变化、升级步骤和需要关注的事项。

维护者启用仓库的私密漏洞报告和秘密扫描功能。构建日志、部署元数据和自动评论仅保留
必要的技术信息，实例配置和凭据保存在各自的私有环境中。
